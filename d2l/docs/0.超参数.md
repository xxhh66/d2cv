# 超参数

## 1.`batch_size`

```bash
# 核心权衡
batch_size 越大 → 梯度越稳定（噪声小），但收敛速度慢，内存消耗大
batch_size 越小 → 梯度噪声大（增加探索性），收敛快，但训练不稳定

# 常见的有效范围
batch_size = 32, 64, 128, 256, 512, 1024, 2048
```

```python
# ============================================================
# 根据硬件选择 batch_size
# ============================================================

def get_recommended_batch_size(device, memory_gb=None):
    """
    根据硬件推荐 batch_size
    """
    if device == 'gpu':
        if memory_gb is None:
            return 64  # 默认
        elif memory_gb >= 24:  # 高端 GPU (RTX 3090, A100)
            return 256
        elif memory_gb >= 16:  # 中高端 (RTX 4080, 3080)
            return 128
        elif memory_gb >= 8:   # 中端 (RTX 4060, 3070)
            return 64
        else:                  # 低端 GPU
            return 32
    else:  # CPU
        return 32  # CPU 训练用小 batch

# 使用示例
print(f"建议 batch_size: {get_recommended_batch_size('gpu', 8)}")  # 64
print(f"建议 batch_size: {get_recommended_batch_size('cpu')}")      # 32
```

从小到大的网格搜索：设置一系列`batch_size`值，训练部分epoch，看看哪个batch_size效果更好。
